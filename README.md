# neCampus

Одностраничный сайт неофициального клиента кампуса ЮЗГУ.

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

В разделе «Как выглядит neCampus» показаны экраны Flutter с тестовыми данными. Шрифт Montserrat распространяется по [SIL Open Font License](assets/OFL.txt).
